## 三、发现并修复的 Bug：decision/analyze 500001

### 3.1 定位证据链（诊断脚本实测）
analyze 报 500001 后查询库内状态：
- 会话已创建，但 `status=RUNNING`（卡死）
- `analyses n=1` → **分析明细行已成功落库**
- `latestAnalysisId=null`、`messages n=0` → `markAnalyzed()` 没执行成功

→ 崩点锁定在 `markAnalyzed()` 这条 UPDATE。

### 3.2 根因
`decision_sessions.latest_run_id` 在 V1 建表时是 **BIGINT**，但网关生成的 runId 是字符串 `"run_<snowflake>"`（`AiInvocationGateway: "run_" + IdWorker.getIdStr()`）。字符串写入 BIGINT 列 → Postgres `invalid input syntax for type bigint` → 未捕获异常 → 全局兜底 500001。

其余所有 run_id 列（agent_runs / credit_ledger / decision_analyses）都是 VARCHAR(64)，**唯独这一列建错了**。面试链路之所以正常，是它的落库路径不经过这列。

### 3.3 修复内容（3 文件，编译通过 EXIT=0）

| 文件 | 改动 |
|---|---|
| `V8__decision_session_latest_run_id_string.sql`（新增） | `ALTER COLUMN latest_run_id TYPE VARCHAR(64) USING ::TEXT` |
| `DecisionSession.java` | `latestRunId` Long → String（否则读回 VARCHAR 报 Bad value for type long） |
| `DecisionServiceImpl.analyze()` | 落库段包 try/catch：失败时置会话 FAILED + log.error + 抛明确错误（兑现"失败要可见"，不再留卡死 RUNNING 会话） |

已重新打包：`bff/target/lq-deepseek-bff-1.0.0-SNAPSHOT.jar`（49.4MB，V8 已在包内）。

## 四、漏洞扫描报告（全代码库）

### 🔴 P0（建议立即修）
1. **`/admin/**` 无权限校验** — `SaTokenConfig` 只做 `checkLogin()`，任何注册用户都等价于管理员：可 CRUD 模型配置、改计费价格（直接影响全站计费）。`User` 实体甚至没有 role 字段。修法：加 role 字段 + Sa-Token 注解/拦截器校验管理员身份。
2. **`/billing/recharge` 任意自助充值** — 任何登录用户可给自己充任意额度，额度体系形同虚设。修法：充值应走支付回调或仅管理员可调。

### 🟠 P1
3. **GraphController.evidence IDOR** — 按 `resume:/job:/interview:` 前缀用全局主键查证据，**不带 userId 过滤**，可越权拉他人简历/JD 内容（PII 泄露）。其余模块均已做 `requireOwned`，唯独这里漏了。
4. **`/admin/models/{id}/test` SSRF** — baseUrl 可指向任意外网/内网地址做探测。修法：白名单校验 URL。
5. **CORS 通配 + 凭据** — `allowedOriginPatterns("*")` + `allowCredentials(true)` 且暴露 `lq-token` 头，任意站点可带凭据跨域调用。修法：收紧 origin 白名单。
6. **Swagger 未鉴权** — `/v3/api-docs/**`、`/swagger-ui/**` 在白名单里，公网可直接看全部 API 结构。生产 profile 建议关闭。
7. **DB 弱默认密码** — `lq_deepseek_pwd` 硬编码在 application.yml（已有 Bug5 改造用 `${LQ_DB_PASSWORD:默认值}`，生产务必用环境变量覆盖并改强密码）。

### ✅ 扫过且干净的
SQL 注入（全 `#{}` 无 `${}`）、路径穿越（SHA-256 文件名 + 扩展白名单）、decision/interview/resume/kb/profile/billing 的越权（均带 userId 过滤）、XSS（markdown 先转义无 dangerouslySetInnerHTML）、兑换码原子消费、SSE/Gateway 的 userId 取自 Sa-Token 而非前端参数。
