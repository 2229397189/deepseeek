## 一、产品定位

Chiron Agent —— AI 求职评估与模拟面试平台。

三句话概括：

1. 以**用户能力画像**为基座数据，向内驱动简历、岗位评估、面试三件事；
2. 所有 AI 结论（评分、题目、薄弱点）**沉淀回画像**，越用越准；
3. 平台侧提供**模型管理 + 知识库混合检索**两个后台抓手，保证 AI 输出可控可解释。

## 三、页面级规格

### 3.1 工作台（首页）

| 项 | 内容 |
| --- | --- |
| 主标题 | 今天想准备哪一场？ |
| 输入框 | 占位符「发岗位链接、贴 JD、贴简历...」 |
| 模型选择 | 下拉，默认 `deepseek-chat` |
| 附加开关 | Mock 流水线 |
| 交互 | 输入后自动识别意图（JD / 简历 / 面试），路由到对应能力 |

### 3.2 简历中心

三栏布局：

```
[ Markdown 编辑区 ]  [ 简历信息预览 ]  [ 辅助助手对话框 ]
```

- 能力：AI 润色（选中文本 → 生成建议 → 一键应用 / 回退）、保存信息、保存正文、导出 PDF；
- 预览区带排版参数：缩放比例（76%）、间距（14mm）、页码（1/1）；
- 简历数据平台内部打通：在平台内做面试 / JD 分析时**无需重复上传简历**；
- AI 依据简历信息生成内容，支持把生成结果应用到正文。

### 3.3 JD 分析（岗位评估）

评测流水线可视化（分步展示，可观测）：

```
parse_jd → load_profile → match_score → 生成建议
```

输出：

- 综合匹配分（0-100，示例 75 / 100）
- 主要风险点
- 结论动作（示例：建议推进 apply）
- 薄弱点识别 → 生成 TODO 建议

核心机制：**内部数据驱动**，以用户能力画像为基座，融合过往经历、平台内面试表现、岗位真实要求三项打分。

### 3.4 AI 面试

左栏：面试记录列表（岗位名 / 日期 / 得分，示例「Java 后端开发工程师 2024-08-30 得分 0」）

右栏（面试室）：

| 控件 | 说明 |
| --- | --- |
| AI 面试官对话区 | 逐题提问、追问 |
| 回答输入框 | 「输入你的回答，或点击麦克风开始语音作答...」 |
| 麦克风 | 实时语音转写 |
| 结束面试 | 结束并生成评分 |
| 开启摄像头 | 视频面试 |
| 构思板 | 作答辅助画板 |
| 模型选择 | `deepseek-chat` |

出题策略（视频明确）：

1. 简历驱动出题，题目与候选人经历深度关联；
2. **薄弱点刻意追问**：识别到 Redis / Spring Boot 等知识点薄弱，会在整场流程中反复提问以巩固；
3. 结合简历与个人经历特点生成个性化问题。

### 3.5 Agent 可视化 / 知识图谱

- 结构：候选人为中心 → 向外三层（简历 / 求职 / 面试）→ 每层挂载抽取出的技能 / 项目 / 岗位知识点；
- 节点状态：**红色 = 薄弱**，AI 读取画像时据此加权追问；
- 图例：候选人、简历/求职/面试、技能/项目/岗位、能力分层、岗位关联；
- 操作：刷新、放大、缩小、拖拽。

### 3.6 用户能力追踪 / 用户画像

- 能力标签：如 `java_basic`、`JD 未覆盖项`；
- **待确认的长期记忆**：AI 推断出的长期记忆进入待确认队列，用户可逐条纠正（输入框 + 提交），纠正后作为权威记忆；
- 说明：AI 判断不一定正确，用户可在此限制 / 纠偏。

### 3.7 系统管理

**模型管理**

- 管理 DeepSeek 及其他 OpenAI 兼容 API 的接入信息（base_url / model / api_key）；
- token 计费管理入口；
- 额度账本、兑换激活。

**知识库管理**

- 混合检索（向量 + 全文）；
- 检索框（示例输入「检索 Java」）；
- 文档过滤（按 标题 / document-id 筛选）；
- 文档内容预览区（文档列表 + 正文）。

## 四、企业级架构增强（结合简历知识点）

在视频功能之上，补齐企业落地必需的分层与治理能力：

```
web (React + TS)  →  BFF (Java / Spring Boot 3)  →  agent-service (Python)
```

| 层 | 职责 |
| --- | --- |
| web | 页面渲染、交互、SSE 流式消费 |
| BFF | 认证鉴权、资源访问控制、计费额度、API 聚合、SSE 透传 |
| agent-service | 评估 / 画像 / 报告 / 面试状态的权威实现 |

BFF 侧企业级能力清单：

1. **Single-flight AI 调用治理**：Redis Lua + 状态机（owner / follower / 心跳续租 / 失败接管 / 结果回放），压测下防击穿；
2. **统一 AI Invocation Gateway**：所有出站 AI 调用唯一入口，统一超时、重试、模型路由、计量、审计；
3. **Agent Kernel 抽象**：Agent 生命周期与状态机统一（`agent_runs`），支持断点恢复；
4. **Agent Context 治理**：上下文快照切片（`context_snapshots` / 切片表），控制 token 预算与压缩；
5. **知识库混合检索**：pgvector + PostgreSQL FTS + RRF 融合 + rerank；
6. **计费额度**：钱包 + 流水 + 幂等键 + 预授权冻结结算；
7. **Schema 演进**：Flyway 版本化迁移，V1 核心表、V2 知识库与上下文；
8. **认证**：Sa-Token + Redis 会话，资源级归属校验。
